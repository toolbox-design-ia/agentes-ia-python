# Agents IA avec Python — Code du livre

Dépôt companion de **« Agentes de IA con Python »** (Henry Ramírez Reyes, Studio35).

Code organisé par chapitre dans `capitulos/`, avec les trois projets complets dans `proyectos/`. L'annexe A du livre explique pas à pas le téléchargement du dépôt, la création de l'environnement et la configuration des clés d'API avec plafond de dépense.

## Un dépôt, trois éditions

Ce dépôt est partagé par les éditions espagnole, anglaise et française du livre. Le code est unique (identifiants en anglais); chaque édition imprime les fragments avec les commentaires dans sa langue.
